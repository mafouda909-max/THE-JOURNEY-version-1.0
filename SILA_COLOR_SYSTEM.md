# SILA / صلة — Master Color System v3

The warm peach/coral accent family has been retired from the identity.

## Brand palette

| Role | Token | HEX | Usage |
| --- | --- | --- | --- |
| Brand Ink | `ink / deep` | `#08264A` | Logo, primary navigation, anchors, dark-on-light CTA |
| Signal Blue | `signal` | `#2E6FD8` | Active selection, connection moments, interactive emphasis |
| Signal Sky | `sky` | `#7CC8E8` | Supporting highlight, focus, selection, visual signature |
| Information Air | `air / wash` | `#DFEBF1` | Information fields, calm surfaces, light hierarchy |
| Paper | `paper / mist` | `#F5F1E8` | Main editorial background |
| Dark | `dark / inverse` | `#071829` | Footer, deep surfaces, reverse applications |

## Functional colors

These are semantic only and are not part of the brand accent language.

- Verified: `#22634A`
- Verified background: `#E6F1EC`
- Warning text: `#8A5B00`
- Warning background: `#FFF3C4`
- Error: `#A42C32`
- Error background: `#FBE9E8`

## Rules

1. No peach/coral/orange brand accent.
2. `Signal Blue` is the strong interaction accent.
3. `Signal Sky` is the light relationship/focus accent.
4. Verification remains green; blue must never imply verification.
5. Warning gold is functional only, never a signature brand color.
6. The logo stays Brand Ink / white unless a monochrome application requires black.
7. “قرار سفر أوضح” uses light Air/Sky behavior on the dark hero, not a warm accent.
8. “انضم كوكيل” uses Brand Ink/Navy as the primary acquisition CTA.
