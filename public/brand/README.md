# SILA production brand assets

This directory contains code-consumable masters for the current approved **SILA / صلة** identity.

## Files

- `sila-logo-ar.svg` — Arabic master for light backgrounds
- `sila-logo-ar-white.svg` — Arabic reverse master
- `sila-logo-en.svg` — approved English artwork
- `sila-logo-primary.svg` — bilingual stacked master
- `sila-logo-primary-white.svg` — bilingual reverse master
- `sila-app-icon.svg` — web/PWA icon master

## Non-negotiable rules

- Do not retype the logo in UI.
- Preserve the approved English artwork.
- Preserve the Arabic kasra relationship so it reads as belonging to **ص**, not as a fatha belonging to **ل**.
- Product/UI typography remains separate from the logo artwork.
- Do not derive a new mark from these files without brand review.

Raster app-store, splash and social masters are maintained in the Master Brand Asset Package until a binary-asset delivery path is wired into the repository.
